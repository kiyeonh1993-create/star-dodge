# 별똥별 피하기 (Star Dodge)

떨어지는 별똥별을 피해 최대한 오래 살아남는 간단한 브라우저 게임입니다.
HTML 파일 하나(`index.html`)로 만들어졌고, 별도의 설치나 빌드가 필요 없습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 / 터치 | 우주선이 포인터를 따라 이동 |
| 방향키 또는 WASD | 우주선 이동 |
| 클릭 / 스페이스 | 게임 시작 및 다시 시작 |

## 규칙

- 별똥별에 닿으면 게임이 끝납니다.
- 살아남은 시간만큼 점수가 오르고, 시간이 지날수록 별똥별이 더 빠르고 자주 떨어집니다.
- 최고 점수는 브라우저의 `localStorage`에 저장됩니다.
